# @deepseek-ai/dsh-hemi-model-access-ui

[English](README.md) | 中文

## 概述

桌面配置加载 Hemi 的「模型接入」页面，提供订阅账号、New API 导入和 API Key 接入。订阅账号在额度可用时显示周限和五小时剩余额度。每个型号提供紧凑的设置、测试和删除图标，附有本地化的无障碍名称和提示。拉取型号使用带搜索的弹窗，确认勾选后才添加。API 接入和订阅模型均可覆盖显示名称、token 限额及文本／图片输入能力。删除最后一个型号仍保留连接和凭据。

## 使用本包

桌面配置隐藏原生「账号和余额」「模型」tab 及侧边栏账号菜单，账号操作集中在「模型接入」中。「订阅」与「API」tab 支持方向键、Home 和 End。API tab 的「接入 New API」打开弹窗。桌面端默认使用 HTTPS，可信的自建站点需要时可选择 HTTP。在弹窗内登录后，点击「登录完成，继续」。只有一个令牌分组时直接显示模型；有多个分组时先选择分组。勾选模型后点击「导入模型」，应用会创建令牌、验证模型并保存连接。关闭弹窗保留草稿，不取消原生导入；进度或结果仍显示在 API tab 中。无法读取导入状态时，弹窗会自动重试，并在恢复后清除提示。导入成功会刷新连接列表。点击「完成」关闭结果，重新打开「接入 New API」即可填写新站点。没有桌面桥接时，弹窗用于导入已有令牌。 接入失败按已知代码给出固定建议（完成登录、重试模型列表、重新打开站点）；其他失败只显示安全操作摘要，不显示协调器的原始消息。

「订阅」tab 中所有账号共用同一个 `SubscriptionCard` 组件。DeepSeek 通过 `account.connection` 复用原生登录和账号状态，以充值余额和赠金余额代替限额进度条。登录后自动读取原生 `deepseek-account` 目录，共用的模型行提供设置、测试和删除，拉取型号使用与其他订阅相同的搜索勾选弹窗。已登录订阅将拉取型号图标放在重新授权前，提供本地化提示。原生提供方将选择保存在 `selectedModels` 中，空列表也会明确保存；查询会重新读取全部可用候选，已删除型号可以再次添加。额度与余额刷新共用同一个图标按钮，提供本地化提示并在刷新期间禁用。余额刷新和退出登录使用原生账号操作，退出前确认对运行中任务的影响。

<a id="use-this-package"></a>

VVCode 账号卡片只显示已选型号与分组数及「管理分组与模型」入口。每次授权在卡片挂载时读取一次全部授权分组，弹窗每次打开都复用这一快照，反复打开不再发请求。弹窗以可折叠列表展示模型；已有启用模型的组默认展开。搜索匹配分组名与模型名，不清除选择。各组显示用量倍率和已选数；目录读取失败时总数显示未知。读取目录只列出分组和模型，不创建 Key，也不要求确认。顶部唯一的「刷新目录」用一次请求重读整个目录；并发打开与读取会复用同一个进行中的读取，不会中断重发。目录读取失败时保留旧数据并显示提示；某分组目录读取失败显示局部重试提示，不当作没有模型；两者都通过「刷新目录」重试，进行中状态显示在按钮上。新模型默认不勾选。勾选只修改草稿，点击「保存选择」时，若新增启用模型需要连接，统一确认一次并仅列出相关分组，再创建或复用调用 Key 并原子保存发生变化的选择。已有连接或仅移除模型不要求创建确认。取消、Escape、点击外部或关闭弹窗均丢弃草稿，不保存也不准备连接。刷新保留目录中仍有效的草稿选择。保存后弹窗保持打开，直到写入完成且一次全新目录读取更新账号摘要；失败时保留草稿供重试，保存中禁止误关。除挂载读取和保存后读取外，只有授权变化、快照缺失或失败以及显式刷新会触发读取；没有按时间轮询。已保存的勾选项进入聊天选模列表；取消勾选仅清除本地选择，保留远端 Key 与目录项。设置和测试使用对应组的提供方，且要求该模型已保存启用、草稿中也保持勾选。空目录、读取失败和授权过期分别提示。授权过期时保留本地选择并允许取消勾选，但禁用启用、设置和测试。登录、取消、重新授权和本地断开仍可使用。Key 创建结果不明时，即使刷新也不再创建该组 Key；请先向 VVCode 确认状态，再断开并重新接入。远端授权需通过 VVCode 网页的授权令牌管理撤销。

VVCode 标题区显示账号余额及每个有效订阅的剩余量、总量和到期时间，不把订阅额度合并进钱包。不限额和暂无有效订阅均明确显示。界面仅格式化服务端规范化的金额或 token 数量，不作换算。刷新失败时保留同次授权的数据并显示警告。缺少订阅权限时提示重新授权，余额仍可见；授权过期或更换时清除旧用量并取消未完成的读取。

Key 预设只提供连接地址，不预填模型 ID。保存连接前，需要从接口读取或手动输入型号。拉取弹窗每次打开都重新读取服务端，并提供「刷新」操作。搜索位于可滚动的模型列表上方，底栏显示全部已选数量，包括被筛选隐藏的型号；「全选」只操作匹配的型号。刷新失败时清空候选列表并显示错误与重试入口，不删除已保存的型号。New API 导入后的连接使用同一设置编辑器。订阅与 API Key 卡片渲染同一个共用的 `ProviderCardContent`，API Key 的拉取型号入口位于卡片头部。

模型设置可编辑显示名称、上下文长度、最大输出 token 及文本／图片输入类型。编辑器直接展示生效值，包括继承的图片能力，始终显示文本／图片选项。保存未改动的值会保留继承；清空可选文字或 token 字段会移除对应覆盖值。新连接的模型草稿随连接保存；已有型号的设置单独确认保存。取消对应弹窗不修改设置。

模型测试期间，播放图标变为旋转加载图标，并禁用该行操作，其他型号仍可测试。成功结果保留在型号旁；测试和删除失败通过应用全局 Toast 提示，关闭设置后仍可见。并发失败按顺序显示。

## 模型体验

<a id="model-experience"></a>

### 连接编辑

#### 模型看到的内容

The editor submits account operations to the `model-access` Host plugin, which owns import validation requests.

#### Token 影响

单纯编辑不发送模型请求；显式验证导入可能消耗提供方 token。

#### KV Cache 影响

编辑器不添加对话前缀；选择导入模型可能改变提供方缓存复用。

## 已知限制与延期工作

<a id="known-limitations-and-deferred-work"></a>

- 浏览器登录需要桌面壳。没有桌面桥接时，可以使用已有令牌导入表单。
- 保存新增启用的 VVCode 分组时，经确认创建或复用 Hemi 专用调用 Key，不设单独额度和期限，仍受账号余额与分组权限限制。账号授权令牌（PAT）过期后 Hemi 拒绝调用，但远端模型 Key 不会随 PAT 过期或本地断开而失效。远端授权需通过 VVCode 网页或管理员管理。
