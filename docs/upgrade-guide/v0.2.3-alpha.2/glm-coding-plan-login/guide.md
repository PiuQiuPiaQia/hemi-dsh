# GLM Coding Plan browser sign-in

English | [中文](guide.zh.md)

## Change

Hemi opens Z.ai China instead of the direct BigModel sign-in for new GLM Coding Plan authorizations. New sign-ins require a linked BigModel account. Existing valid grants and model selections stay in place.

## Migration

1. If GLM Coding Plan is already connected and working, keep the existing connection.
2. When you need to sign in, open **Model access → GLM Coding Plan** and start authorization. In the browser, use the Z.ai China account linked to the BigModel account that holds your plan.
3. Return to Hemi and confirm that GLM Coding Plan shows as connected. If the account is not linked, complete the link with the provider before retrying.
