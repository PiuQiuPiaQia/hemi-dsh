# Hemi 备份保留已有会话

[English](guide.md) | 中文

## 变更

备份操作现在位于「设置 → 备份」，使用独立导航入口，不再作为通用设置中的卡片。

Hemi 备份原先按修改时间处理 Session 文件冲突。恢复现在保持已有 Session 目录内的所有文件不变，将不同或额外的备份代际另存。缺失的 Session 目录仍可恢复，其他数据保留较新文件的合并策略。无效 manifest 和归档路径会在恢复前被拒绝。

备份现在包含 `$DSH_HOME/hemi-memory/`。旧归档仍可读取，但可能缺少此前备份遗漏的长期记忆、每日日志和便签。

## 迁移

1. 向其他机器迁移数据前，先在「设置 → 备份」中重新备份。旧归档无法恢复从未收集的文件。
2. 恢复时查看预览。已有会话保留本地历史；冲突的备份代际可在 `$DSH_HOME/restore-safety/restore-*/dsh/sessions/` 中检查。不要将其覆盖到活跃或已提交的 Session 代际上。
3. 重启应用，确认缺失的会话与 Hemi 记忆存在。恢复失败时保留原归档和操作报告中的安全副本目录；合并可能已完成部分操作。
