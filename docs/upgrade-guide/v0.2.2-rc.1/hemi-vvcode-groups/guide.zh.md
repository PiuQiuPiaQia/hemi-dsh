# VVCode 连接支持多个分组

[English](guide.md) | 中文

## 变更

包含单组 `hemi-model-access.vvcodeConnection` 设置的 Hemi Profile 改用 `vvcodeConnections` 下的独立分组连接。VVCode 卡片通过管理弹窗列出全部应用授权分组，不再切换一个当前分组。各组拥有独立的模型 Key、目录和已启用型号；账号余额及有效订阅仍为账号级信息。

原分组继续使用 `vvcode` 提供方 ID，保留已保存会话中的型号引用。其他分组获得独立的提供方 ID。新型号不会自动启用。型号名称带有所属分组，因此同名型号仍可区分。

## 迁移

1. 保留现有 Profile patch 和凭据库。Hemi 会接纳已保存的分组、Key 引用、型号选择及型号覆盖值；此转换不需要手动复制 Key 或重新授权。
2. 打开 **设置 → 模型接入 → 订阅 → VVCode**，再打开分组与模型管理弹窗，确认原分组的型号仍已勾选。尚未同步的分组没有已勾选型号。
3. 使用弹窗顶部唯一的刷新入口更新分组和模型。同一授权范围内重新打开弹窗会复用已成功读取的结果。这些读取不创建或获取模型 Key。勾选型号并保存时，只有新增启用且没有已保存连接的分组才需要确认创建 Key。取消弹窗只放弃勾选，不准备调用连接。已有连接会复用。
4. 从两个分组选择同一型号，确认名称能区分所属分组。取消一个分组中的勾选不得停用另一个分组的同名型号。

转换中断时，旧设置会保留到分组集合提交成功。目录读取失败时通过统一拉取入口重试，已保存选择保持不变。不要删除凭据，也不要重复创建结果不明的令牌。[模型接入参考](../../../../packages/hemi/model-access/README.zh.md)说明授权及恢复限制。
